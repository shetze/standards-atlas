## Direction of travel

Standards Atlas evolves from deterministic document engineering toward a reviewed, cross-standard knowledge graph:

1. extract and normalize source documents;
2. construct canonical clauses with evidence and lineage;
3. classify clauses using independent structural dimensions;
4. resolve references and relationships;
5. publish knowledge domains;
6. compare standards across domains;
7. support traceable engineering analysis and assistants.

Planned capabilities are not part of the current contract until implemented and documented in the changelog.
