# Roadmap

This directory contains the detailed implementation roadmaps for the major
evolution themes of standards-atlas.

The top-level `ROADMAP.md` intentionally provides only a strategic overview.
Each document in this directory expands one roadmap item into an engineering
plan that can evolve independently.

## Planning principles

Roadmaps are living engineering documents rather than fixed schedules.

Each roadmap should describe:

- Motivation
- Historical context
- Current state
- Target architecture
- Milestones
- Open questions
- Risks
- Success criteria
